## 配置与启动

MySQL 通过 SPRING_DATASOURCE_URL、SPRING_DATASOURCE_USERNAME、SPRING_DATASOURCE_PASSWORD；Redis 通过 SPRING_DATA_REDIS_HOST、SPRING_DATA_REDIS_PORT、SPRING_DATA_REDIS_PASSWORD、SPRING_DATA_REDIS_DATABASE 注入。YAML 不含真实密码；SQL 初始化为 never。应用不会自动建表、删表、清表或导入演示数据。

开发默认 dev；生产显式 SPRING_PROFILES_ACTIVE=prod，单独启用 prod，文档关闭、CORS 来源默认空。APP_CORS_ALLOWED_ORIGINS 可配置明确来源。JWT_SECRET、地图服务端密钥继续保留为环境配置，本阶段不读取密钥或硬编码。

Spring Boot 不会自动读取根目录 dotenv，可使用 backend/scripts/dev.cjs（Node 20.12+）安全加载，或通过 IDE/部署平台注入。工具的 --config-file 避免与 Node 自身 --env-file 参数冲突。完整命令见 backend/README.md。

~~~powershell
# 在 backend 中，设置好 JAVA_HOME/MAVEN_HOME 后：
node .\scripts\dev.cjs verify-live
node .\scripts\dev.cjs run
~~~

本机现有 JDK 21：C:/Users/yxl/.jdks/ms-21.0.11，可通过 --java-home 指定；Maven 位于 D:/idea/apache-maven-3.9.4，可通过 --maven-home 指定。日志记录请求编号、方法、路径、状态及耗时，不记录查询串、请求体、Authorization。真实凭据、私密文件、日志、构建产物均在 Git 忽略范围。

## 已实现接口

| 方法/路径 | 说明 |
| --- | --- |
| GET /api/v1/films?page=1&pageSize=10 | Controller → Service → Mapper → 实际 MySQL；只查 PUBLISHED，id DESC |
| GET /actuator/health | MySQL/Redis 综合健康，只返回状态 |
| GET /v3/api-docs | dev OpenAPI 文档 |
| GET /swagger-ui.html | dev Swagger UI，302 到 index.html |

业务 API 为 code/message/data/requestId；分页 data 包含 records/total/page/pageSize/pages。page=1..1000000，pageSize=1..100，默认 1/10；参数不合法返回 400，越界页为空，主键字符串输出。错误保留真实 HTTP 状态；校验错误不回显原值，内部错误不回显堆栈、SQL、凭据。

Actuator/OpenAPI/Swagger/CORS 保留标准协议格式；其他业务路由（包括 POST films）均需要认证。prod 匿名访问文档为 401；测试认证后的访问也为 404，证明文档没有注册。
