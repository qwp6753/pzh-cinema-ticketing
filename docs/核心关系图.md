# 核心业务关系

以下为主要实体关系，全部字段及关联以数据字典和SQL为准。

## 影院与售票

~~~mermaid
erDiagram
    cinema ||--o{ cinema_hall : 包含
    cinema_hall ||--o{ cinema_seat : 布局
    film ||--o{ cinema_film : 影院上架
    cinema ||--o{ cinema_film : 本院片库
    cinema_film ||--o{ cinema_screening : 排片
    cinema_hall ||--o{ cinema_screening : 放映
    cinema_screening ||--o{ screening_seat : 库存快照
    cinema_seat ||--o{ screening_seat : 按场次复用
    sys_user ||--o{ seat_hold : 锁座
    seat_hold ||--o{ seat_hold_item : 选择座位
    screening_seat ||--o{ seat_hold_item : 锁座历史
    seat_hold ||--o| ticket_order : 生成订单
    sys_user ||--o{ ticket_order : 购票
    ticket_order ||--o{ ticket_order_item : 逐票明细
    screening_seat ||--o{ ticket_order_item : 售票历史
    ticket_order ||--o{ payment_transaction : 支付尝试
    payment_transaction ||--o{ payment_refund : 原路退款
    ticket_order_item ||--o| ticket : 电子票
    ticket ||--o{ ticket_qr_token : 动态凭证
    ticket ||--o{ ticket_verification_log : 验票记录
    ticket_order ||--o{ after_sale_request : 退票改签
    after_sale_request ||--o{ after_sale_item : 逐票退改
~~~

## 权限、会员与互动

~~~mermaid
erDiagram
    sys_user ||--o{ sys_user_role : 获得授权
    sys_role ||--o{ sys_user_role : 角色
    cinema |o--o{ sys_user_role : 可选影院范围
    sys_role ||--o{ sys_role_permission : 权限分配
    sys_permission ||--o{ sys_role_permission : 权限项
    sys_user ||--o| member_account : 平台会员
    member_level ||--o{ member_account : 等级
    member_account ||--o{ member_points_ledger : 积分流水
    sys_user ||--o{ cinema_member : 本院会员
    cinema ||--o{ cinema_member : 会员关系
    coupon_template ||--o{ user_coupon : 领券
    sys_user ||--o{ user_coupon : 持有
    user_coupon ||--o{ coupon_usage : 订单使用历史
    marketing_activity ||--o{ activity_participation : 报名
    sys_user ||--o{ activity_participation : 参与
    ticket_order_item ||--o| film_review : 购票评价
    film_review ||--o{ review_reply : 商家回复
    sys_user ||--o{ user_feedback : 反馈
    user_feedback ||--o{ feedback_reply : 沟通
~~~

图中的历史关系为一对多；“当前有效的占用至多一个”由生成列唯一键和事务规则限制，例如场次库存有效明细、优惠券占用和在途退改。
