# 需求与数据表对应

| 角色 | 功能 | 主要表/视图 |
|---|---|---|
| 用户端 | 注册、登录、个人资料 | sys_user / sys_user_role / user_login_log |
| 用户端 | 分类、区域、热度检索和影片详情 | film / film_category / film_category_rel / cinema / sys_region / cinema_screening / v_film_rating |
| 用户端 | 影院选择、场次选择和可视化座位 | cinema_film / cinema_hall / cinema_seat / cinema_screening / screening_seat |
| 用户端 | 实时锁座、下单、支付 | seat_hold / seat_hold_item / ticket_order / ticket_order_item / payment_transaction / payment_callback_event |
| 用户端 | 我的收藏 | user_favorite_film |
| 用户端 | 我的订单、票夹及动态二维码 | ticket_order / ticket_order_item / ticket / ticket_qr_token |
| 用户端 | 退票、部分退票、同院改签 | after_sale_request / after_sale_item / payment_refund / order_status_history |
| 用户端 | 平台会员积分、优惠券 | member_level / member_account / member_points_ledger / coupon_template / user_coupon / coupon_usage |
| 用户端 | 影院公告、促销、失物招领 | announcement |
| 用户端 | 影片评价、留言反馈 | film_review / review_reply / user_feedback / feedback_reply |
| 用户端 | 活动参与与奖励 | marketing_activity / activity_participation |
| 影院管理员 | 个人信息、本院资料及本院片库 | sys_user / sys_user_role / cinema / cinema_film |
| 影院管理员 | 影厅、物理座位与布局管理 | cinema_hall / cinema_seat |
| 影院管理员 | 排片计划、场次库存与票价策略 | cinema_screening / screening_seat / cinema_pricing_rule |
| 影院管理员 | 本院会员信息 | cinema_member / sys_user（最小必要字段） |
| 影院管理员 | 本院订单及现场扫码核销 | ticket_order / ticket_order_item / ticket / ticket_qr_token / ticket_verification_log |
| 影院管理员 | 退票改签审批及退款追踪 | after_sale_request / after_sale_item / payment_refund |
| 影院管理员 | 本院公告、活动、评价与反馈处理 | announcement / marketing_activity / film_review / review_reply / user_feedback / feedback_reply |
| 影院管理员 | 实时票房与上座率看板 | v_cinema_realtime / v_screening_inventory / stat_cinema_daily |
| 系统管理员 | 分类、全局影片统筹、上下架与资讯 | film_category / film / film_category_rel（影片详情字段承载资讯维护） |
| 系统管理员 | 入驻影院资质审核 | cinema_application / cinema |
| 系统管理员 | 影院管理员申请审核 | cinema_admin_application / sys_user_role |
| 系统管理员 | 平台用户、会员与动态权限 | sys_user / member_account / sys_role / sys_permission / sys_role_permission / sys_user_role |
| 系统管理员 | 评价审核、敏感词和审计 | film_review / sensitive_word_rule / moderation_log / sys_audit_log / user_login_log |
| 系统管理员 | 全平台公告与活动 | announcement / marketing_activity / activity_participation |
| 系统管理员 | 攀枝花整体票房及活跃用户 | stat_platform_daily / stat_cinema_daily / user_activity_event / v_platform_daily_activity |
| 公共支撑 | 缓存一致性、回调重试和幂等 | outbox_event / idempotency_record / payment_callback_event |

全局影片资讯按本课题中的影片简介、海报、预告片、上映状态等资料维护设计。如果后续明确增加独立新闻栏目，再增加film_news；当前不凭空增加新闻工作流。退款与改签只在同一影院内处理，券与会员优惠可组合，一单最多使用一张券，按“场次/座位定价→会员折扣→优惠券”顺序计算。
