## 复现与边界

可复用脚本位于database/tests/audit-live.cjs，使用Node.js 24及本机mysql客户端。脚本只读取被忽略的.env.local，密码通过子进程环境传递，不写入命令参数或报告。报告及结构JSON不包含登录用户名、密码或API密钥。

在项目根目录执行：

~~~powershell
node ./database/tests/audit-live.cjs --mysql-client 'D:/MySQL/MySQL Server 8.0/bin/mysql.exe' --report-dir './work/database-audit'
~~~

仅检查结构时增加--structure-only；首次准备开发样例时可增加--seed-demo，但只会在业务表全空时导入，存在演示数据则复用，其他已有业务库不会被覆盖。普通完整核验会在事务中暂时写入测试记录，应在开发库执行。

本报告覆盖数据库结构、数据引用完整性及SQL事务能力，不等同于登录、真实支付、Redis锁和三端API联调已完成；后端仍须落实权限隔离、排片冲突检查和业务状态流转。完整的84个唯一索引及99组外键、162对字段类型可查同目录的结构核验JSON。
