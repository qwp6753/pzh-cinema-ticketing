## 复现方式

需要Node.js及本机mysql/mysqld二进制。运行下列命令会在新临时目录初始化专用测试实例，选择动态端口，验证完成后关闭它；测试脚本不连接现有3306端口，也不删除用户库。已有同名测试工作目录会报错，请每次使用新目录。

~~~powershell
node ./database/tests/verify.cjs --mysql-bin 'D:/MySQL/MySQL Server 8.0/bin' --work-dir './work/db-check-new'
~~~
