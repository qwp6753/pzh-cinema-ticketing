# 数据字典

共 55 张业务表，字段、索引和约束与 01_schema.sql 从同一份模型生成。数据库状态码采用英文字符串；Java 使用枚举映射。所有表默认包含 id、created_at、updated_at。

## 账号权限

### sys_region — 区域字典

| 字段 | 类型及默认值 | 说明 |
|---|---|---|
| id | BIGINT NOT NULL AUTO_INCREMENT | 主键；应用使用 Java Long，接口以字符串返回 |
| parent_id | BIGINT NULL | 父区域 |
| region_code | VARCHAR(32) NOT NULL | 项目内区域编号，不作为行政区划编码 |
| region_name | VARCHAR(64) NOT NULL | 区域名称 |
| level_no | TINYINT NOT NULL DEFAULT 1 | 层级：1城市、2区县 |
| sort_no | INT NOT NULL DEFAULT 0 | 显示顺序 |
| status | VARCHAR(24) NOT NULL DEFAULT 'ENABLED' | 状态；ENABLED/DISABLED |
| created_at | DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3) | 创建时间；统一使用北京时间 |
| updated_at | DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3) ON UPDATE CURRENT_TIMESTAMP(3) | 最近更新时间 |

**索引与约束**

- PRIMARY KEY `id`
- UNIQUE KEY `region_code`
- `parent_id` → `sys_region(id)`，删除和更新均 RESTRICT
- `CHECK (level_no IN (1,2))`
- `CHECK (`status` IN ('ENABLED', 'DISABLED'))`

### sys_user_role — 用户角色授权

| 字段 | 类型及默认值 | 说明 |
|---|---|---|
| id | BIGINT NOT NULL AUTO_INCREMENT | 主键；应用使用 Java Long，接口以字符串返回 |
| user_id | BIGINT NOT NULL | 被授权用户 |
| role_id | BIGINT NOT NULL | 角色 |
| scope_type | VARCHAR(24) NOT NULL DEFAULT 'GLOBAL' | 授权范围；GLOBAL/CINEMA |
| cinema_id | BIGINT NULL | 影院范围；全局角色为NULL |
| scope_key | BIGINT GENERATED ALWAYS AS (IFNULL(cinema_id, 0)) STORED | 唯一性辅助列；全局范围映射为0 |
| granted_by | BIGINT NULL | 授权人 |
| expires_at | DATETIME(3) NULL | 授权到期时间；NULL为长期 |
| created_at | DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3) | 创建时间；统一使用北京时间 |
| updated_at | DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3) ON UPDATE CURRENT_TIMESTAMP(3) | 最近更新时间 |

**索引与约束**

- PRIMARY KEY `id`
- UNIQUE KEY `user_id, role_id, scope_key`
- `user_id` → `sys_user(id)`，删除和更新均 RESTRICT
- `role_id, scope_type` → `sys_role(id, scope_type)`，删除和更新均 RESTRICT
- `cinema_id` → `cinema(id)`，删除和更新均 RESTRICT
- `granted_by` → `sys_user(id)`，删除和更新均 RESTRICT
- KEY `cinema_id, user_id`
- `CHECK ((scope_type = 'GLOBAL' AND cinema_id IS NULL) OR (scope_type = 'CINEMA' AND cinema_id IS NOT NULL))`
- `CHECK (`scope_type` IN ('GLOBAL', 'CINEMA'))`

| active_user_count | INT NOT NULL DEFAULT 0 | 全平台按用户去重；禁止直接相加影院DAU |
| new_user_count | INT NOT NULL DEFAULT 0 | 新增普通用户数 |
| active_cinema_count | INT NOT NULL DEFAULT 0 | 营业影院数 |
| calculated_at | DATETIME(3) NOT NULL | 汇总计算时间 |
| created_at | DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3) | 创建时间；统一使用北京时间 |
| updated_at | DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3) ON UPDATE CURRENT_TIMESTAMP(3) | 最近更新时间 |

**索引与约束**

- PRIMARY KEY `id`
- UNIQUE KEY `stat_date`
- `CHECK (gross_sales >= 0 AND refund_amount >= 0 AND paid_order_count >= 0 AND active_user_count >= 0 AND new_user_count >= 0 AND active_cinema_count >= 0)`

### outbox_event — 事务消息发件箱

| 字段 | 类型及默认值 | 说明 |
|---|---|---|
| id | BIGINT NOT NULL AUTO_INCREMENT | 主键；应用使用 Java Long，接口以字符串返回 |
| event_no | VARCHAR(64) NOT NULL | 全局事件编号 |
| aggregate_type | VARCHAR(64) NOT NULL | 聚合类型 |
| aggregate_id | VARCHAR(64) NOT NULL | 聚合标识；多态引用 |
| event_type | VARCHAR(96) NOT NULL | 事件类型 |
| payload | JSON NOT NULL | 不含凭证的事件数据 |
| status | VARCHAR(24) NOT NULL DEFAULT 'NEW' | 投递状态；NEW/PROCESSING/SENT/FAILED |
| retry_count | INT NOT NULL DEFAULT 0 | 重试次数 |
| next_retry_at | DATETIME(3) NOT NULL | 下次重试时间 |
| locked_until | DATETIME(3) NULL | 消费者租约到期 |
| locked_by | VARCHAR(64) NULL | 消费者实例标识 |
| last_error | VARCHAR(500) NULL | 错误摘要 |
| created_at | DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3) | 创建时间；统一使用北京时间 |
| updated_at | DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3) ON UPDATE CURRENT_TIMESTAMP(3) | 最近更新时间 |

**索引与约束**

- PRIMARY KEY `id`
- UNIQUE KEY `event_no`
- KEY `status, next_retry_at`
- KEY `status, locked_until`
- `CHECK (retry_count >= 0)`
- `CHECK (`status` IN ('NEW', 'PROCESSING', 'SENT', 'FAILED'))`

### idempotency_record — 业务请求幂等记录

| 字段 | 类型及默认值 | 说明 |
|---|---|---|
| id | BIGINT NOT NULL AUTO_INCREMENT | 主键；应用使用 Java Long，接口以字符串返回 |
| user_id | BIGINT NOT NULL | 请求发起人 |
| operation_code | VARCHAR(64) NOT NULL | 操作类型 |
| key_hash | VARCHAR(64) COLLATE utf8mb4_bin NOT NULL | 客户端幂等键摘要 |
| request_hash | VARCHAR(64) COLLATE utf8mb4_bin NOT NULL | 请求内容摘要；同键异参必须拒绝 |
| status | VARCHAR(24) NOT NULL DEFAULT 'PROCESSING' | 状态；PROCESSING/SUCCEEDED/FAILED |
| resource_type | VARCHAR(64) NULL | 结果资源类型 |
| resource_id | VARCHAR(64) NULL | 结果业务编号 |
| expires_at | DATETIME(3) NOT NULL | 幂等窗口结束 |
| processing_until | DATETIME(3) NOT NULL | 执行租约到期时间 |
| owner_token | VARCHAR(64) COLLATE utf8mb4_bin NOT NULL | 执行者租约令牌 |
| created_at | DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3) | 创建时间；统一使用北京时间 |

- KEY `expires_at`
- KEY `status, processing_until`
- `CHECK (`status` IN ('PROCESSING', 'SUCCEEDED', 'FAILED'))`
